DESPERTAR NA PRÁTICA — ENTREGA COMPLETA

COMO ABRIR
1. Extraia o ZIP.
2. Para visualizar sem instalar nada, abra preview/ABRIR-PREVIEW.html.
3. Para editar, use index.html e styles.css. Mantenha as imagens junto do código.

EXECUÇÃO NO SEU SISTEMA
Esta página é HTML e CSS estáticos. Não usa framework, npm, banco de dados,
Supabase, autenticação ou etapa de build.
Se tiver Python 3, abra o terminal na pasta extraída e execute:
  python3 -m http.server 4173
Depois abra http://localhost:4173 no navegador local.
Também é possível servir a pasta com a extensão Live Server ou outro servidor estático.

CONTEÚDO
index.html: estrutura, conteúdo e links da landing page.
styles.css: estilos responsivos. O fundo da primeira dobra usa a imagem
  login-floresta-eterea.webp com 8% de opacidade no seletor .hero::before.
assets/: versões otimizadas das imagens utilizadas.
Imagens na raiz: materiais originais recebidos, preservados.
preview/ABRIR-PREVIEW.html: cópia independente com estilos e imagens incorporados;
  é uma exportação para visualizar. Depois de editar o código, precisa ser regenerada.
preview/Visual-desktop.png e Visual-celular.png: capturas completas para referência.
revisao/primeira-dobra.png: captura da alteração de fundo solicitada.
README.md: documentação técnica.
MANIFESTO-SHA256.txt: lista dos arquivos e hashes para conferir a integridade.
